# ЛР-7 — Консольное приложение

## Цель
Объединить знания из ЛР1–ЛР6 в единое работающее приложение с интерактивным CLI-интерфейсом.

## Структура

```
src/lab07/
├── README.md       # Описание
├── main.py         # Точка входа
├── cli.py          # Меню, ввод/вывод
├── app.py          # Бизнес-логика
├── exceptions.py   # Собственные исключения
├── storage.py      # Сохранение/загрузка JSON
├── data/
│   └── services.json  # Файл данных
```

## Функциональность

Меню (10 пунктов):
1. Добавить сервис — создание Sersev / ComputeServer / StorageServer / ProxyServer
2. Показать все сервисы — таблица с именем, типом, статусом, загрузкой, задачами
3. Найти сервис — поиск по имени с детальным выводом
4. Удалить сервис — удаление с подтверждением
5. Поиск по атрибуту — поиск по name / status / type
6. Фильтрация — по диапазону загрузки или по статусу
7. Сортировка — по имени / макс. задачам / загрузке (возр./убыв.)
8. Детальная информация — детальный отчёт о сервисе
9. Редактирование (добавление/удаление задач)
0. Выход — сохранение данных в JSON

## Слои архитектуры

- `cli.py` — только ввод/вывод, без бизнес-логики
- `app.py` — бизнес-логика, работа с коллекцией
- `models` (lab01, lab03) — классы предметной области
- `exceptions.py` — `ItemNotFoundError`, `DuplicateItemError`, `InvalidInputError`
- `storage.py` — JSON-сериализация

## Запуск

```bash
python -m src.lab07.main
```

Автоматическая загрузка данных при старте, автосохранение при выходе.
