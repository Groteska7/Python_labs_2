# Лабораторная работа 5: Функциональное программирование и Стратегии

## Реализованные возможности:
1. 3 стратегии сортировки:
   - По имени сервера
   - По максимальному количеству задач
   - По статусу и имени
   
2. 2 стратегии фильтрации:
   - Фильтр работающих серверов
   - Фабрика фильтров по нагрузке
   
3. Функции преобразования:
   - Конвертация в словарь
   - Фабрика применения скидки к задачам
   
4. Callable-стратегии:
   - Фильтрация по статусу
   - Сокращение количества задач

5. Методы коллекции:
   - `sort_by()`: сортировка по стратегии
   - `filter_by()`: фильтрация по предикату
   - `apply()`: применение функции к элементам
   
6. Цепочки операций:
   - Поддержка fluent interface: `filter().sort().apply()`
